# PaleoSecrets Business

Sitio de divulgación sobre dinosaurios, recursos educativos y futura monetización con afiliados y productos digitales.

## Primera versión

- Portada cinematográfica responsive.
- Archivo inicial de especies.
- Biblioteca de recursos próximos.
- Sección editorial.
- Formulario de interés preparado para conectar a una base de emails.
- SEO básico.

## Próximo paso técnico

Conectar el formulario a una base de datos y a un proveedor de correo antes de anunciar que las suscripciones están activas.
